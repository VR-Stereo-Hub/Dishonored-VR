Dishonored VR - quick start
===========================

This build has native stereo, head and positional tracking, motion controllers,
drawn hands and weapons, controller-aimed Blink, and the HUD on VR anchors.

The settings in dishonored_vr.ini already ship at the values this build was
tuned and headset-tested at, so a fresh install matches the development machine
without editing anything. Do not hand-edit it to "fix" performance before you
have run it once.


1. COPY THE FILES

Put d3d9.dll, dvr_steamvr32.dll and openvr_api.dll next to the game exe:

    <Steam>\steamapps\common\Dishonored\Binaries\Win32\

Delete any dxvk_d3d9.dll left there by a release before 41.0.

dishonored_vr.ini goes in the SAME folder. Without it you get the code defaults
rather than the tested profile, and they are not the same thing.


2. GAME-SIDE SETTINGS

Run the game once so it writes its own config, then, from the folder you
unzipped:

    powershell -ExecutionPolicy Bypass -File setup-game-ini.ps1 -VRBaseline

It backs each file up first, changes four values (engine frame smoothing, depth
of field, the engine's vsync, mouse smoothing) and prints what it changed. It is
safe to run twice.

The game REWRITES those whenever you open its own video options, so run it again
if you visit them.

Turn Motion Blur OFF in the game's options.

Do NOT set the render resolution in the game's video options. On this build the
game's own ini is inert for render size: [Screen] RenderWidth, RenderHeight,
RenderFullscreen and VirtualMode in dishonored_vr.ini are the only place it
lives, and the proxy puts them on the engine's command line. The F10 Display tab
has the picker, and it takes effect at the next launch.


3. HEADSET AND RUNTIME

[VR] Runtime=auto picks the 32-bit OpenXR runtime your system registers and
falls back to the bundled SteamVR shim when there is none. You should not need
to change it.

  Quest over Virtual Desktop: start VD streaming with VDXR selected as the
  OpenXR runtime. Use 90 Hz with SSW off.

  90 Hz IS DELIBERATE and is not "as high as it goes". A higher refresh measured
  WORSE here: the frame cost lands the pair cadence on a bad beat and the image
  ghosts on head turns. Start at 90 and leave it there.

  SteamVR headsets (Index, Vive, WMR through SteamVR): start SteamVR first. The
  mod uses the bundled shim, dvr_steamvr32.dll.

  A native 32-bit SteamVR/OpenXR path exists but still reports an inverted world
  (VR-146). Prefer the shim.

Then launch the game from Steam.


4. IN GAME

  F10   the settings overlay: Display, View, Comfort, Aim, HUD, Hands
  F5    recenter
  F3    toggle head tracking

The render resolution shipped here (2750x2850 per eye) was chosen for a Quest 3
at 90 Hz. If your headset or GPU differs, change it in F10 > Display rather than
anywhere else, and re-launch.


5. IF SOMETHING GOES WRONG

Run "Collect VR Support.cmd" and send what it produces. It gathers the log and
your settings.

Files the mod writes next to the game exe:

  dishonored_vr.ini        your settings
  dishonored_vr.log        SEND THIS WITH ANY BUG REPORT
  dishonored_vr.prev.log   the run before it - rotation is only one deep, so
                           copy the log out before relaunching after a fault
  dishonored_vr_crash.txt  only after a crash

Delete dishonored_vr.ini to reset every setting to the shipped profile. Create
an empty disable_vr.txt in that folder to disable the mod without uninstalling.

Startup logos are suppressed by the proxy, including replacement movie files
from texture packs. To opt out, add [Startup] SkipMovies=0 to dishonored_vr.ini
before launch. Story movies are not affected.

Known issues and troubleshooting: KNOWN_ISSUES.txt and TROUBLESHOOTING.txt.
